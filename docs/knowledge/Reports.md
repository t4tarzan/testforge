# Reports

Back to [[TestForge]]. Three surfaces, **one structure** — all render/serialize
the same `ShowcaseDimensionGroup[]` shape (built by
`src/lib/buildDimensionGroups.ts` from a `/clone-and-analyze` result, mirroring
the mcp-server distill), so they're identical in content.

## 1. Live generated report (web)
Shown after an analysis in the `/run-test` and `/managed` flows
(`src/components/testrunner/ReportStep.tsx`, `DimensionBreakdown.tsx`):
- Header stats + radar.
- **Findings by dimension** — expandable per-dimension cards: score + progress
  bar, finding count, *how it's tested* (method/coverage from
  `dimensionMeta`), each finding's severity/location/description + **Fix**.
- **Generate Tests (Tier 2)** button → [[Tier2-Sandbox]] (BYOK/paid; 402 → "add
  a key or upgrade").
- **Export**: JSON · Markdown · PDF. Markdown via the shared
  `src/lib/buildMarkdownReport.ts`.

## 2. Self-host dashboard download
`localhost:33221` → after analysis: **Download Report (Markdown)** + **Download
JSON** + Print/Save PDF. The Markdown matches the curated format: dimension
scores table, per-dimension Method + Coverage + findings (with fixes), Test
Coverage section, Security Findings summary, and a **Tier-2** section listing
generated tests + sandbox pass/fail when a run was done.

## 3. Curated "In-the-Wild" reports
`testforge.run/#/in-the-wild/<slug>` (summary) and `.../full` (whitepaper).
Pre-computed JSON in `src/data/showcaseReports/*.json`, generated by
`scripts/generate-showcase-report.sh`. Public examples: full-stack-fastapi-
template, langchain, supabase, testforge (self-audit). A private dkubex report
is kept **local only** (gitignored) — used for the journey video/PDF, never
deployed.

## Markdown report = single source
`buildMarkdownReport()` (web) and the self-host dashboard's `downloadReport()`
produce the same sections. Per-dimension Method/Coverage come from
`dimensionMeta` (web imports it; the dashboard fetches `/dimension-meta.json`,
generated from the same file). This is why "web export = self-host download =
curated report" structurally. See [[Scoring]] for the numbers behind them.
